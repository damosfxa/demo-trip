# Demo Website Info Peserta

Demo untuk calon klien: peserta acara registrasi (nama, departemen, nomor HP) dari HP, lalu melihat jadwal, info penting, dan pengumuman. Panitia melihat daftar peserta dan mengunduhnya sebagai Excel.

Data contoh disimpan di localStorage browser (tanpa database).

```
npm install
npm run dev
```
